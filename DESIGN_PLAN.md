# Zsh configuration design plan

## Preferred approach: pinned modules, no Oh My Zsh runtime

Remove Oh My Zsh from the runtime path and source a small set of pinned modules
directly. This removes implicit plugin ordering, broad alias policy, duplicate
`compinit`, and the framework's warm/cold startup overhead.

The external seam is a deliberately small `.zshrc`; module interfaces hide
initialization details. The explicit source list is the interface. It is more
predictable and more testable than adding a generic plugin loader.

## Module layout

```text
.zshenv                       global-RC gate
.zshrc                        ordered module interface
modules/
  bootstrap.zsh               XDG paths, dependency root, PATH helper
  options.zsh                 curated Zsh options
  local.zsh                   machine-local configuration seam
  history.zsh                 bounded, private history
  completion.zsh              compinit, styles, fzf-tab, deferred Bun
  navigation.zsh              zoxide and fzf widgets
  history-ui.zsh              Atuin and autosuggestions
  prompt.zsh                  Powerlevel10k
  lazy-tools.zsh              thefuck, extract, sysinfo
  keys.zsh                    final binding table
  syntax.zsh                  fast-syntax-highlighting, sourced last
config/
  p10k.zsh                    compact prompt policy
  atuin/config.toml           privacy-safe defaults
  local.d/                    ignored, repository-local overrides
deps.lock                     exact dependency commits and tool versions
scripts/
  install                     deterministic installer and atomic linker
  uninstall                   rollback
  import-history              one-time legacy history import
  wizard                      machine-local settings wizard (preview before apply)
  benchmark.sh                performance interface
  check-syntax.sh             zsh -n interface
lib/
  extract.zsh                 portable extraction implementation
tests/
  smoke.zsh                   interface and fallback checks
  pty_smoke.py                PTY-backed ZLE and history checks
  perf.zsh                    cold/warm benchmark
  wizard.zsh                  wizard validation and isolation checks
  run                         complete verification interface
vendor/                       ignored; exact dependency checkouts
```

Avoid a generic plugin-loader framework: it would be shallow compared with the
complexity it adds.

## Startup order

1. **Global RC gate**
   - User `.zshenv` disables Zsh's `GLOBAL_RCS` option for interactive shells.
   - This skips the distribution's duplicate `compinit` and broad aliases while
     preserving user startup order and history persistence.

2. **P10k instant prompt**
   - Use the official snippet generated by P10k `v1.21.0`.
   - Keep it as the first executable block in `.zshrc`.

3. **Bootstrap**
   - Establish `$XDG_CONFIG_HOME`, `$XDG_CACHE_HOME`, `$XDG_STATE_HOME`.
   - Resolve the repository and `vendor` directories.
   - Add only existing PATH directories, idempotently.
   - Create cache, state, and user-config directories with mode `700` without
     changing umask.

4. **Options and local policy**
   - Apply curated options.
   - Source repository and user local files with stdout suppressed.

5. **History**
   - `HISTFILE=$XDG_STATE_HOME/zsh/history`
   - `HISTSIZE=50000`, `SAVEHIST=50000`
   - Enable append-only, duplicate-resistant history and `HIST_IGNORE_SPACE`.
   - Add a surviving `zshaddhistory` hook that rejects every leading-whitespace
     logical command, not only a leading space.

6. **Completion**
   - Set styles before `compinit`.
   - Use `$XDG_CACHE_HOME/zsh/zcompdump-$ZSH_VERSION`.
   - Run normal audited `compinit`; never set `ZSH_DISABLE_COMPFIX`.
   - Source fzf-tab after `compinit`.
   - Register Bun through a deferred `_bun` function.

7. **Navigation**
   - Initialize zoxide in the parent shell.
   - Source only fzf's pinned `key-bindings.zsh`, with its Ctrl-R command empty.

8. **History UI**
   - Initialize Atuin with `--disable-up-arrow --disable-ai`.
   - Source autosuggestions afterward.
   - Use the local `history` autosuggestion strategy to avoid a subprocess per
     keystroke.

9. **Prompt**
   - Source Powerlevel10k and the compact `config/p10k.zsh`.
   - Disable the gitstatus daemon and auto-installer; use local `vcs_info`.

10. **Lazy tools**
    - Install one-shot `fuck`, `extract`, and explicit `sysinfo` wrappers.

11. **Keys**
    - Apply the final binding table after all widgets exist.

12. **Syntax**
    - Seed fast-syntax-highlighting's optional theme locally.
    - Source the sole highlighter last.

## Explicit key ownership

| Key | Owner | Enforcement |
|---|---|---|
| Ctrl-R | Atuin fuzzy history | Atuin init plus final binding; fzf fallback only without Atuin |
| Ctrl-T | fzf file selection | Final file-widget binding; unbound without fzf |
| Alt-C | fzf directory selection | Final directory-widget binding; unbound without fzf |
| Tab | fzf-tab | Final binding; native completion fallback |
| Up Arrow | Native Zsh history | Final `up-line-or-history` binding |
| `?` | Literal insertion | No Atuin AI binding |
| `/` in vi command mode | Native vi history search | Restore `vi-history-search-backward` |
| `z` / `zi` | zoxide | No competing alias |

Do not source zsh-autocomplete, zsh-autopair, or zsh-opencode-tab.

## Lazy-loading mechanism

Only shell-mutating integrations need wrappers. Plain binaries have no startup
cost until invoked.

- **thefuck:** a `fuck` wrapper evaluates local `thefuck --shell zsh` output in
  the parent shell on first use; a transient failure leaves the wrapper intact
  for a later retry.
- **extract:** a one-shot wrapper sources `lib/extract.zsh` in the parent shell.
- **Bun completion:** the first completion request replaces `_bun` in the
  parent shell with Bun's generated function; a transient failure leaves the
  stub intact for a later retry.
- **sysinfo:** explicit invocation only; `fetch --frames 1` avoids the original
  2,000-frame animation.
- **conda/opam:** excluded from the core and placed in user local files; do not
  auto-activate Conda or run `opam init` at startup.
- **Atuin and zoxide:** remain eager because deferring them changes observable
  history and directory-tracking behavior.
- **fzf:** its bindings are eager, but the fzf binary starts only when used.

Never initialize shell state in a background subshell. Atuin may prepare its own
search index internally because that work does not mutate the parent shell.

## Security and privacy decisions

- Keep completion's `compaudit` enabled.
- Disable Atuin automatic sync and update checks; enable secret filtering.
- Exclude leading-whitespace commands in Zsh and Atuin, including tab-prefixed
  entries. An accept-line wrapper preserves the raw privacy state for Atuin's
  preexec path, and the Atuin preexec hook honors that state.
- Treat sync as an explicit user opt-in because command history is sensitive.
- Evaluate only trusted output from locally installed binaries.
- Never evaluate downloaded shell code during startup.
- Disable Powerlevel10k's gitstatus daemon and auto-installer.
- Remove global `GOSUMDB=off` and `GOPROXY=direct`.
- Do not set `PYTHONPATH` with an empty leading component.
- Keep VPN, paste-service, IDE, CUDA, and personal tool policy in local files.
- Require local modules to produce no stdout.

## Migration and deployment

1. Build and validate the repository without modifying the live shell.
2. Copy prompt policy into `config/p10k.zsh` and use the official P10k snippet.
3. Move machine-specific rules to ignored local files.
4. Test with isolated HOME/XDG directories.
5. Import old Zsh history exactly once, excluding whole logical records whose
   first character is whitespace.
6. Run smoke, installer, PTY, privacy, and performance suites.
7. Validate an isolated Atuin candidate, then atomically replace `~/.zshrc`
   and `~/.zshenv` with repository symlinks while retaining collision-proof
   backups.
8. Verify a real login shell.
9. Roll back by restoring the startup files; do not delete the old OMZ install,
   Atuin database, vendor data, or local policy during the rollback period.

## Performance budgets

| Measurement | Budget |
|---|---:|
| Warm interactive startup, p50 | ≤60 ms |
| Warm startup, p95 | ≤80 ms |
| First clean startup, including `compinit` | ≤300 ms |
| First `thefuck` invocation | ≤200 ms additional |
| First Bun completion | ≤50 ms additional |

Hard requirements:

- No startup network access.
- No Python, Bun, or fzf process at startup.
- No `fetch`/fastfetch execution.
- No shell-mutating initialization in a background subshell.
- No individual startup initializer over roughly 25 ms except a cold
  `compinit`.

## Rejected alternative: retain Oh My Zsh and add a lazy plugin manager

This retains `oh-my-zsh.sh`, then layers Zinit or native lazy hooks around
Atuin, zoxide, fzf, thefuck, and completions.

Reject it because OMZ still owns `compinit`, styles, theme loading, and plugin
order; its startup overhead remains; plugin managers commonly defer or
background initialization, recreating the parent-shell bug; and combining
frameworks adds more implicit ordering than it removes.
